# Models

Optional. Characters can be drawn from `.glb` files instead of from code (see "Models" in `CLAUDE.md`).
The files themselves are **not committed** (see `.gitignore`): each person downloads them from the source.

For every model you use, add a line here saying where it comes from and under which licence, with the file name,
because `npm run check` warns when a model is not listed. Example:

```
- knight.glb: KayKit Adventurers 2.0, Kay Lousberg (kaylousberg.itch.io), CC0
```

Check the licence on the source's own page before you use or share a model. Never use characters that belong to someone else's series.
